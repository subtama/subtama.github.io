# ASP登録＆広告リンク差し替え手順（早川さんの手作業）

記事内リンクは現在「公式サイトURL（仮）」です。ASPに登録して**アフィリエイト広告リンク**に差し替えると、そこから収益が発生します。

## 1. ASPに無料登録（審査あり・無料）
おすすめは以下。VOD/サブスク案件が揃い、Amazon/楽天もまとめて扱える。
- **もしもアフィリエイト** — Amazon/楽天/VODを1アカウントで。初心者向けで審査が通りやすい
- **A8.net** — 案件数最大手。VOD無料体験案件が豊富
- **バリューコマース** — 大手案件・単価高め

登録時は「サイトURL」を聞かれるので、**先に公開（Step4）してURLを用意**しておくとスムーズ。

## 2. 提携申請する主な案件（VOD）
各ASPの管理画面で検索して提携申請：
- U-NEXT / DMM TV / Lemino / dアニメストア / Hulu / Disney+ など
- 「無料トライアル系」は報酬発生条件が"無料登録"なので成約が軽い＝狙い目

## 3. リンクを差し替える
提携が承認されると、各案件の「広告リンク（URL）」が発行されます。それを記事の`::cta ...::`や本文リンクのURLに置き換えます。

差し替えは Claude Code に任せられます。例：
> 「content/ の各記事の U-NEXT のリンクを、この広告URL（xxxx）に全部差し替えて、build.pyでビルドして」

一元管理したい場合は `data/links.json` を作り、Claude Codeにリンクを集中管理させる運用も可能（次の改善で対応）。

## 4. 規約の注意（成果を飛ばさないため）
- ステマ規制対応: 記事冒頭の「プロモーションを含みます」表記は実装済み（テンプレに固定）
- 各ASP/広告主の禁止事項（虚偽・誇大・比較の根拠なき断定）を避ける
- クッキー有効期間内に成約されると報酬。SNSからの送客も有効
